# goit-js-hw-12

Домашнє завдання №12: розширення застосунку пошуку зображень (Pixabay API)
пагінацією та рефакторинг запитів під `async/await`.

## Встановлення

```bash
npm install
```

## Розробка

```bash
npm run dev
```

## Збірка

```bash
npm run build
```

## Налаштування

Отримайте свій безкоштовний ключ на [pixabay.com](https://pixabay.com/api/docs/)
і вставте його в `src/js/pixabay-api.js` замість `API_KEY`.

## Функціонал

- Пошук зображень за ключовим словом через Pixabay API.
- Пагінація: по 15 зображень за запит, кнопка `Load more`.
- Плавний скрол сторінки після довантаження нової групи зображень.
- Індикатор завантаження та повідомлення (iziToast) про помилки, відсутність
  результатів і кінець колекції.
- Перегляд зображень у модальному вікні (SimpleLightbox).
